Part 1: Key Concepts
Week 1: Unity Editor Tour and Your First Script
What is a GameObject, and what is a Component? A GameObject is anything that exists in your scene. A Component is a piece of behavior or data attached to it (a Transform, a collider, a script).
What does every script inherit from? MonoBehaviour, the base class that hooks your code into Unity's built-in events such as Start and Update.
What do the Hierarchy, Inspector, Project, and Console panels do? Hierarchy lists every GameObject in the scene. Inspector shows the components on the selection. Project shows your files and assets. Console shows Debug.Log messages, warnings, and errors.
What is the difference between the Scene view and the Game view? The Scene view is where you build and arrange objects. The Game view shows what the player sees through the in-game camera and is what runs in Play mode.
Which component does every GameObject have? A Transform (position, rotation, and scale).
Week 2: Scripting Lifecycle, Inheritance, Encapsulation, and Debugging
What is the difference between Awake and Start? Awake runs once when the object is created, before any Start. Start runs once after every Awake in the scene has finished, so use it for setup that depends on other objects.
What is the difference between Update and FixedUpdate? Update runs once per rendered frame, so frame time varies. FixedUpdate runs on a fixed timestep, so use it for physics and Rigidbody code.
Why multiply movement by Time.deltaTime in Update? Frame time varies, so deltaTime makes movement happen at a constant real-world speed instead of depending on frame rate.
What do virtual, override, and base do? virtual marks a base class method a derived class may replace. override replaces it in the derived class. base.Method() calls the parent's version.
What is the difference between a public field and a [SerializeField] private field? Both show in the Inspector, but other scripts can edit a public field and cannot touch a [SerializeField] private one directly. This is encapsulation.
Week 3: GameObjects, 2D Physics, Prefabs, and Object Pooling
What are the three Rigidbody2D Body Types? Dynamic is fully simulated and affected by gravity and forces. Kinematic is moved by your script, not by forces. Static never moves (solid ground often has just a collider).
What is the difference between a trigger and a collision? A collision is a solid hit handled by OnCollisionEnter2D. A trigger has Is Trigger checked, so objects pass through it while it fires OnTriggerEnter2D. Use triggers for zones, pickups, and goals.
What is the difference between a Tag and a Layer? A Tag is a single label such as "Enemy" that you check with CompareTag. A Layer is a numbered category (0 to 31) used mainly by physics and rendering, such as the Layer Collision Matrix.
What does a Physics Material 2D control? Friction and bounciness of a collider.
What is a prefab? A reusable GameObject template saved as an asset. Editing the prefab updates every instance of it.
What is object pooling? Creating a fixed number of objects up front and reusing them with SetActive instead of calling Instantiate and Destroy repeatedly.
Week 4: Version Control, the Input System, and PlayerPrefs
Why use version control on a Unity project? It keeps real history beyond Ctrl+Z, acts as a safety net, and lets people collaborate on the same project.
What does the .gitignore file do? It lists paths that Git should never track, no matter what.
What are an Input Action, an Action Map, and a Binding? An Input Action is a named action such as "Jump," separate from any key. An Action Map is a named group of actions. A Binding is the actual key, button, or stick mapped to an action.
What is the difference between wasPressedThisFrame and isPressed? wasPressedThisFrame is true only on the frame the key goes down (good for a jump). isPressed is true every frame it is held (good for walking).
What is PlayerPrefs? A built-in key-value store that persists between sessions. Save with PlayerPrefs.SetInt("HighScore", 1500) and PlayerPrefs.Save(). Load with PlayerPrefs.GetInt("HighScore", 0), where 0 is the default if the key is missing.
Week 5: Scene Management and Tilemaps
What is the Build Settings list? The ordered list of scenes included in the build (File > Build Settings). A scene not on it cannot be loaded.
How do you load a scene from code? SceneManager.LoadScene("Level2") or by build index, after adding using UnityEngine.SceneManagement.
What does LoadSceneMode.Additive do? It loads a second scene on top of the current one so both coexist. A pause overlay is a typical use.
What are a Grid, a Tilemap, and a Tile Palette? The Grid is the parent that sets the cell size. A Tilemap renders one layer of painted tiles. The Tile Palette (Window > 2D > Tile Palette) is where you pick tiles and paint them.
How do you make painted tiles solid? Add a Tilemap Collider 2D to the Tilemap GameObject.
Week 6: Lighting, Materials, and UI
What are the four light types? Directional (distant, like the sun), Point (all directions, has Range), Spot (a cone), and Area (a rectangle, baked only).
What is the difference between real-time and baked lighting? Real-time is recalculated every frame and is required for anything that moves. Baked is precomputed into a lightmap, is cheap, and only works for Static objects that never move.
What is a Material, and what is a Shader? A Material is an asset holding a shader plus input values (color, texture, sliders). A Shader is a small GPU program that decides how a surface's pixels are drawn.
What is the difference between renderer.material and renderer.sharedMaterial? .material gives an instance copy, so only that object changes. .sharedMaterial edits the original asset and changes every object that uses it.
How do you wire a Button to a method? In the Button's On Click () list, click +, drag in the object holding the script, and choose the method from the function dropdown.
How does Time.timeScale pause a game? Setting it to 0 freezes everything driven by Time.deltaTime, and 1 is normal speed. Update still runs, so the Escape key and menu buttons still respond.
Week 7: Audio, Persistent Objects, ScriptableObjects, and Pure C# Classes
What are the AudioClip, AudioSource, and AudioListener? The AudioClip is the sound file, the AudioSource is the speaker that plays it, and the AudioListener is the ears. You need all three to hear anything.
What is the difference between Play() and PlayOneShot(clip)? Play() plays the AudioSource's own clip and restarts it if called again. PlayOneShot(clip) plays any clip you pass in on top of what is already playing, so rapid presses overlap instead of cutting off.
What does DontDestroyOnLoad do? It keeps a GameObject alive when a new scene loads, so music does not restart and a manager keeps its data.
How does the singleton guard prevent duplicates? It uses a static Instance field. In Awake, if Instance is already taken by another object, destroy this one and return. Otherwise set Instance to this and call DontDestroyOnLoad.
What is a ScriptableObject? A data container that lives as an asset file in the Project window. It is never attached to a GameObject and has no Update.
What is a pure C# class? A plain class with no : MonoBehaviour, no GameObject, and no lifecycle. You create it with new (for example new Health(30)), and it never appears in the Inspector.
Week 8: Animator, Blend Trees, Animation Events, and StateMachineBehaviour
What are an Animation Clip, an Animator, and an Animator Controller? A clip is one recorded motion made of keyframes. The Animator is the component that plays animation. The Animator Controller is the asset holding the states, transitions, and parameters.
When do you use a bool and when a trigger? A bool for a condition that stays true (IsRunning). A trigger for something that happens once (Jump, Attack).
What does Has Exit Time do on a transition? If checked, the transition waits until the clip has played to the Exit Time point (0.75 means 75 percent through). Use it for "finish the clip first" arrows such as Jump back to Idle. Uncheck it for "react right now" arrows such as Idle to Run.
What is a blend tree? A state that mixes several clips continuously along a float parameter, such as Idle, Walk, and Run at thresholds along Speed.
What is an Animation Event? A marker at a chosen moment on a clip that calls a method on a script during playback, such as a footstep sound at foot contact.
Week 9: Noise, Procedural Generation, Particles, and Trails
What does Mathf.PerlinNoise(x, y) return? A smooth value from 0 to 1. Nearby inputs give nearby outputs.
What is a seed in noise terrain? An offset added to the coordinates before dividing by scale. The same seed gives the same world every time, and a new seed gives a new world.
What is a threshold? A cutoff that turns a noise value into a decision, such as wall versus floor. Lowering a wall threshold makes more walls.
What is the difference between a burst and Rate over Time? A burst releases many particles at one instant (sparks on a hit). Rate over Time emits a steady number per second (rain, dust).
What is the difference between ps.Play() and ps.Emit(n)? Play() starts the system as if it just switched on, including its burst. Emit(n) releases exactly n particles immediately, so rapid hits all show feedback.
Week 10: Genre Patterns, Platformers, and Puzzle State Tracking
What is a ground check and why does a jump need one? A small test at the character's feet asking whether something solid is there, often using a Ground layer. Without it the player could jump in mid air.
How does a double jump work? The game counts jumps used since last touching the ground and allows one more in the air. Landing resets the count to zero.
What is a HashSet and why use it for latched switches? A collection that stores each value at most once, so stepping on a lit switch again does not count it twice.
Why is event-driven puzzle code better than checking every frame? Each piece reports when it changes, so the puzzle updates once and checks the goal, and a door can hear "solved" without the pieces knowing about it.
Why can duplicate switch IDs break a puzzle? Two switches sharing an ID are stored as one piece, so the puzzle can never count them separately.
Part 2: Build Practice
On the midterm you are expected to recreate this game in the Unity Editor. The build question uses the game below, so practice building it from these steps until you can do it without them. You will not write scripts: every script is provided, and your job is to build the scenes, set up components, and wire everything together.
The Game: Lantern Dash
Lantern Dash is a small 2D platformer. You run and jump an orange square carrying a lantern across a painted Tilemap level, collect coins, dodge a patrolling enemy, step on two switches to open a door, and reach the glowing goal. The goal returns you to a main menu that shows your best coin count, saved with PlayerPrefs. A and D move, Space jumps, Escape pauses.
Unzip midterm-game-scripts.zip. It holds 9 scripts and 1 audio clip. Scripts: PlayerController (on Player), Coin (Coin prefab), EnemyStats (ScriptableObject, not attached), Enemy (Enemy), Switch (each Switch), Door (Door), GameSession (static score and high score, not attached), SceneLoader (Goal and MenuManager), HudController (GameManager and MenuManager). Audio: coin.wav.
Project Setup (Steps 1 to 5)
Step 1. In Unity Hub choose New project, the Universal 3D template, Editor 6000.3.23f1, name MidtermGame. In Assets create folders Scripts, Audio, Scenes, Prefabs, Materials, Data, Tiles, Input, Sprites, and Animations. Choose Window > Package Manager, open Unity Registry, and install 2D Sprite and 2D Tilemap Editor if they are not already installed (the Universal 3D template does not include them, and Steps 4 to 8 need their menus). Drag the 9 .cs files into Scripts and coin.wav into Audio. The Console must show no red errors.
Step 2. Choose Edit > Project Settings > Player > Other Settings and set Active Input Handling to Input System Package (New) or Both (click Apply if you change it).
Step 3. Choose File > New Scene, select Basic (URP), click Create, then File > Save As and name it Game in Assets/Scenes. Click Main Camera: Position 0, 0, -10, Projection Orthographic, Size 6, Environment Background Type Solid Color 1B2A41. Click Directional Light and set Intensity 0.3.
Step 4. Right-click Assets/Sprites and choose Create > 2D > Sprites > Square, then again for Circle.
Step 5. Click Main Camera, open its Tag dropdown, choose Add Tag, and add Enemy. Open Layers and type Ground in User Layer 6.
Checkpoint. Press Play: a flat dark blue Game view and no Console errors.
Tilemap Level (Steps 6 to 8)
Step 6. Right-click the Hierarchy and choose 2D Object > Tilemap > Rectangular. Rename the Tilemap child Ground, set its Layer to Ground, and add Tilemap Collider 2D.
Step 7. Choose Window > 2D > Tile Palette, create a new palette named LevelPalette in Assets/Tiles, and drag the Square sprite in twice, saving the tiles as GrassTile and DirtTile. Set GrassTile Color to 4CAF50 and DirtTile Color to 6B4F2A.
Step 8. With Active Tilemap set to Ground, paint grass tiles whose bottom edges are at y = -4 from x = -10 to 10, dirt tiles at y = -5 over the same range, and a three tile grass platform at y = -1 with x = -5, -4, -3.
Checkpoint. Press Play: a green and brown strip with a raised platform. The Scene view shows collider outlines on the Ground tiles.
Player (Steps 9 to 13)
Step 9. Choose GameObject > 2D Object > Sprites > Square, rename it Player, Position -9, -2, 0, Sprite Renderer Color E8833A, Order in Layer 5, Tag Player. Add Rigidbody2D (Body Type Dynamic, Gravity Scale 1, Freeze Rotation Z checked) and Box Collider 2D.
Step 10. Right-click Assets/Materials and choose Create > 2D > Physics Material 2D, name it Slick, set Friction 0 and Bounciness 0, and drag it into the Box Collider 2D Material field.
Step 11. Right-click Player and choose Create Empty. Rename the child GroundCheck with Local Position 0, -0.5, 0.
Step 12. Right-click Assets/Input and choose Create > Input Actions, name it PlayerControls, and open it. Delete any default actions. Add an Action Map named Player. Add action Move (Action Type Value, Control Type Vector2) with an Add Up/Down/Left/Right Composite bound to W, S, A, D, and a second composite bound to the arrow keys. Add action Jump (Action Type Button) bound to Space. Click Save Asset.
Step 13. On Player add Player Input (Actions PlayerControls, Default Map Player, Behavior Send Messages) and Player Controller. Set Move Speed 5, Jump Force 9, Ground Check Radius 0.2, Fall Limit -8, drag GroundCheck into Ground Check, and set Ground Layer to Ground.
Checkpoint. Press Play: A and D run the square, Space jumps only from the ground, and falling off the left edge respawns it at the start.
Animator (Steps 14 to 17)
Step 14. Choose Window > Animation > Animation, click Player, click Create, and save the clip as Player_Idle in Assets/Animations. Click Add Property, choose Transform > Scale, click the plus, then key Scale.y as 1.1 at 0:30 and 1 at 1:00.
Step 15. Click the clip name, choose Create New Clip, and name it Player_Run. Add Property Transform > Scale, then key Scale.y as 0.85 at 0:08 and 1 at 0:16. In the Project panel select both clips and check Loop Time.
Step 16. Choose Window > Animation > Animator. In Parameters add a Bool named IsRunning. Make a transition from Player_Idle to Player_Run with condition IsRunning true, and one back with IsRunning false. On both uncheck Has Exit Time and set Transition Duration 0.1.
Step 17. Drag Player from the Hierarchy into the Animator field of Player Controller.
Checkpoint. Press Play: holding D switches the Animator window to Player_Run and the square squashes quickly, releasing it returns to Player_Idle.
Coins, Particles, and Enemy (Steps 18 to 21)
Step 18. Choose GameObject > 2D Object > Sprites > Circle, rename it Coin, Scale 0.5, 0.5, 1, Color FFD54A, Order in Layer 3. Add Circle Collider 2D with Is Trigger checked and the Coin script (Value 1, drag coin into Collect Clip). Drag it into Assets/Prefabs, delete it from the scene, then drag the prefab in three times at (-4, 0.7, 0), (0, -2.2, 0), and (5, -2.2, 0).
Step 19. Choose GameObject > Effects > Particle System, rename it SparkBurst, drag it onto Player, and set Local Position 0, 0, 0. In Main set Looping off, Start Lifetime 0.6, Start Speed 4, Start Size 0.15, Start Color FFD54A, Simulation Space World, Play On Awake off. Set Emission Rate over Time 0 with one Burst at Time 0, Count 15. In Renderer set Order in Layer 10. Drag SparkBurst into the Collect Burst field of Player Controller.
Step 20. Right-click Assets/Data and choose Create > Enemies > Enemy Stats. Name it SlimeStats with Enemy Name Slime, Move Speed 1.5, Color 66BB6A.
Step 21. Create a Circle named Enemy at Position 3, -2.5, 0, Tag Enemy, Order in Layer 4. Add Rigidbody2D (Body Type Kinematic), Circle Collider 2D with Is Trigger checked, and Enemy (Stats SlimeStats, Patrol Distance 2).
Checkpoint. Press Play: the green enemy patrols, touching a coin removes it with an orange spark burst, and touching the enemy sends you back to the start.
Switch and Door Puzzle (Steps 22 to 24)
Step 22. Create a Square named Switch1 at Position -7, -2.8, 0, Scale 0.8, 0.3, 1, Color E53935. Add Box Collider 2D with Is Trigger checked and the Switch script with Switch Id 1. Duplicate it (Cmd+D), rename it Switch2, Position -4, 0.15, 0, Switch Id 2.
Step 23. Create a Square named Door at Position 9, 0, 0, Scale 1, 6, 1, Layer Ground. Add Box Collider 2D and Door (Total Switches 2, Open Height 6.5, Open Speed 3). Drag Door into the Door field of both switches.
Step 24. Create a Square named Goal at Position 10, -2, 0, Scale 1, 2, 1, Color 66E0FF. Add Box Collider 2D with Is Trigger checked and Scene Loader (Trigger Scene MainMenu, Save Score On Trigger checked).
Checkpoint. Press Play: each switch turns green and the Console counts "Switch 1 activated (1/2)". After both, the door slides up. Do not enter the Goal yet.
Light and Material (Steps 25 to 26)
Step 25. Right-click Player and choose Light > Point Light. Rename it Lantern, Local Position 0, 0, -1.5, Color FFB74D, Intensity 15, Range 6.
Step 26. Right-click Assets/Materials and choose Create > Material, name it DoorLit with Shader Universal Render Pipeline/Lit, Base Map color 8D6E63, Metallic 0.3, Smoothness 0.5, and drag it onto Door.
Checkpoint. Press Play and walk toward the door: it glows warm orange as the lantern gets close and is dim far away.
UI, Pause, and Audio Listener (Steps 27 to 31)
Step 27. Choose GameObject > UI > Canvas. If the EventSystem offers Replace with InputSystemUIInputModule, click it. Set Canvas Scaler UI Scale Mode to Scale With Screen Size and Reference Resolution 1920 by 1080.
Step 28. Right-click Canvas and choose UI (Canvas) > Text - TextMeshPro (click Import TMP Essentials if asked). Rename it ScoreText, anchor it top-left (Anchor Presets with Shift and Alt held), Pos X 40, Pos Y -30, Width 500, Height 80, text Coins: 0, Font Size 60.
Step 29. Right-click Canvas and choose UI > Panel, rename it PausePanel. Right-click it and choose UI (Canvas) > Button - TextMeshPro, rename it ResumeButton, Width 500, Height 100, child text Resume.
Step 30. Create an empty GameObject named GameManager and add Hud Controller. Drag ScoreText into Score Label and PausePanel into Pause Panel. On ResumeButton add an On Click () entry, drag GameManager in, and choose HudController > Resume(). Then uncheck PausePanel so it starts hidden.
Step 31. Click Main Camera and confirm it has an Audio Listener component (the Coin plays its sound through it).
Checkpoint. Press Play: the score reads "Coins: 1" after a coin with a coin sound, Escape shows the pause panel and freezes the game (Edit > Project Settings > Time shows Time Scale 0), and Resume continues. Choose File > Save.
Main Menu and Build Settings (Steps 32 to 35)
Step 32. Choose File > New Scene, Basic (URP), save it as MainMenu in Assets/Scenes, and set Main Camera Background Type to Solid Color 1B2A41. Add a Canvas with the same Canvas Scaler settings.
Step 33. On Canvas add a Text - TextMeshPro named BestText (anchored center, Pos Y 100, Width 800, Height 100, Font Size 60, Alignment Center) and a Button - TextMeshPro named PlayButton (anchored center, Pos Y -50, Width 500, Height 100, child text Play).
Step 34. Create an empty GameObject named MenuManager with Hud Controller (drag BestText into Best Label) and Scene Loader. On PlayButton add an On Click () entry, drag MenuManager in, choose SceneLoader > LoadScene(string), and type Game in the box.
Step 35. Choose File > Save, then File > Build Profiles and open the Scene List. Click Add Open Scenes for MainMenu, open Game and add it too, then drag MainMenu to index 0 and Game to index 1.
Checkpoint. Open MainMenu and press Play: "Best: 0" shows, Play loads Game, and the Goal returns to the menu with your coin count as the new Best.
